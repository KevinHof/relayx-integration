## Findings
1. No bulk, export or list-entries route. 12 operations total
   (`docs/relayx/contract-notes-2026-10-19.md`).
2. `/changes` rows are full `Contrainte` objects, not id + changeKind. It is the only route
   keyed on time instead of substance, so it is the candidate for a full extract (Q1).
   Unvalidated.
3. `/entries/{id}/history` returns full versions with a `knowledge` window (Q2 answered by
   contract).
4. `/changes` must be paged with opaque `nextCursor`, not `nextSince`. This conflicts with
   CLAUDE.md rule 4 and with `legacy/relayx_client.py` (`iter_changes_cursor`). New Q8.
5. Quota: contract says per subscription per minute; headers show 15000 per 900 s window;
   CLAUDE.md says 60/min per key. `RateLimit-Reset` looks like seconds, contract says Unix
   timestamp. New Q7.
6. The PDF is not in `docs/relayx/`, so the PDF diff was made against what the repo records
   about it (13 differences listed in the contract notes).
7. `DATABASE_URL` connects as superuser `postgres`. The covalo read-only rule is enforced
   only by discipline.
8. `legacy/` holds only `relayx_client.py`. `build_entries_table.py` and
   `build_product_clusters.py` (named in the brief) are not in the repo.

## Legacy inventory: `legacy/relayx_client.py`
Thin `requests` client. Inputs: env `RELAYX_API_KEY`, `RELAYX_BASE_URL`. Outputs: one JSON file
per call plus `calls.jsonl` under `raw_responses/<run_id>/`, each with request params,
status, timing, byte size, sha256 of raw bytes and of canonical JSON, rate headers.
- Reuse for full extract: request wrapper, 429 handling with Retry-After, canonical hash
  (change detection prototype), metadata record (matches rule 6), batch chunking 50/25.
- Must change: page /changes by `nextCursor`; persist to DB or `data/` instead of
  `raw_responses/`; handle batch `truncated: true` by re-queueing unevaluated items; retry
  5xx by class code; defensive `RateLimit-Reset` parsing; drop `lang` from batch body; add
  `clpIndex`, `colourIndex`, `synonym`; default base URL to `api.relay-x.com`.
- Matching stage: nothing reusable in the repo (scripts missing); the kevin.* tables remain
  as reference outputs.
