# Phase 1: full /changes replay and completeness check (2026-10-19, approved)

## Code
- `src/relayx/client.py`: client ported from legacy (request wrapper, 429 handling, raw and
  canonical hashes). RateLimit-* headers authoritative, waits on Reset when Remaining is too
  low, Reset parsed as seconds or Unix timestamp, retries 5xx and connection errors.
- `src/relayx/changes_replay.py`: phase 1 extractor. Pages by `nextCursor`, stores each page
  raw plus metadata, rewrites a run manifest after every page, resumes from the last stored
  page. `src/relayx/replay_stats.py`: statistics over a stored run.
- `src/relayx/completeness.py`: stratified lookup:batch check against a replay.
- 16 tests (`pytest`): Reset parsing, unit tracking, cursor paging, resume, stats, sampling.
  Nothing is written to the database.
